# Play Today App

Play Today — сервис отзывов о настольных играх для антикафе «Host&Хвост».

Это веб-приложение на Flask, которое позволяет посетителям антикафе делиться впечатлениями об играх. Администратор может загружать фотографии коробок, а гости — читать отзывы и смотреть рейтинг.

Особенности:

* Веб-интерфейс (Jinja2 + Bootstrap) для чтения и написания отзывов.
* JSON API для интеграции с мобильными приложениями.

* Асинхронная загрузка изображений в облако (Dropbox API).
* Система рейтинга (1–10 звезд) и фильтрация по названию игры.

* Защита форм с помощью CSRF (Flask-WTF) и аутентификация (Flask-Login).
